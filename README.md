# Portix Linux

Artix OpenRC + LXQt Wayland desktop with custom pman module intergration inspired by Porteus Linux and its various forks.

Repository is mostly specific to the LXQT desktop enviorment. I'm a massive fan :-) 

Two compositor options are documented:

- **[LabWC](labwc/)** – lighter, more manual control
- **[KWin](kwin/)** – better HDR / Plasma integration

Start with the [Base Install](base-install/).
