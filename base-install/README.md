# Base Install

Common Artix OpenRC base installation files for Portix Linux.

Choose the path that matches the compositor you want to use:

| File | Description |
|------|-------------|
| [lxqt-labwc-base.md](lxqt-labwc-base.md) | Full base install for **LabWC** |
| [lxqt-kwin-base.md](lxqt-kwin-base.md) | Full base install for **KWin** |
| [labwc-post-install.md](labwc-post-install.md) | Extra packages & services after LabWC base |
| [kwin-post-install.md](kwin-post-install.md) | Extra packages & services after KWin base |

### Recommended order

1. Follow the appropriate **base** file for your compositor
2. Reboot
3. Run the matching **post-install** file
4. Continue to the compositor-specific folder (`labwc/` or `kwin/`)
