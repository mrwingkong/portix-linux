# LabWC Path

Documentation for running LXQt under the **LabWC** Wayland compositor.

LabWC is lighter and more manual than KWin. It is a good choice if you prefer full control and lower resource usage.

### Guides in this folder

| File | Description |
|------|-------------|
| [display-panel-setup.md](display-panel-setup.md) | Display & panel configuration |
| [swaync-osd-actions.md](swaync-osd-actions.md) | Volume & brightness OSD with swaync |
| [tablet-mode.md](tablet-mode.md) | Custom tablet mode support |

### Before you start

Make sure you have completed the LabWC base install from the `base-install/` folder first.
